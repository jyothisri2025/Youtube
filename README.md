# 📺 YouTube Homepage Clone – HTML & CSS

A fully responsive, pixel-perfect front-end clone of the YouTube homepage developed using **HTML5** and **CSS3**. This project demonstrates strong skills in layout design, UI structuring, and responsive styling using modern CSS techniques like **Flexbox**, **Grid**, and **Media Queries**.

> ⚠️ This project is built for educational and portfolio purposes only. It does not include any backend functionality or content from YouTube's proprietary services.

---
<hr>

## ✅ Key Features

- ⚙️ **Responsive Layout** – Optimized for desktop view, with clean scaling and spacing.
- 🔍 **Navigation Bar** – Includes logo, search input, and user action icons.
- 📚 **Sidebar Menu** – Vertical navigation with icon-text pairs for various sections.
- 🎞️ **Video Grid** – Thumbnail-based layout showing video previews with titles, channels, and view stats.
- 🧼 **Clean CSS Architecture** – Separation of concerns via modular CSS files.

---
<hr>
## 🧰 Technologies Used

- **HTML5** – Semantic and accessible markup
- **CSS3** – Modular CSS with:
  - Flexbox
  - Grid Layout
  - Media Queries (for responsiveness)
  - Hover effects
  - Custom Scrollbar
